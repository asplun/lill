# Solbrin Lill 主题设计规格

## 目标

把已确认的首页原型落成一个可安装、可切换、可持续维护的 Lill 主题。主题名为 `Solbrin`，目标运行时为 `lill-v2`（主题 API 1.3.x），交付形式包含主题目录与可直接上传的 ZIP。

成功标准是：安装后首页直接使用站点真实文章；首屏影像、文案、长胶囊和下方文章卡片形成连贯场景；鼠标、触屏、键盘和减少动态效果都能完成文章选择；其余 Lill 页面仍可正常阅读和导航。

## 范围与边界

- 目标目录：`lill-v2/frontend/themes/solbrin/`
- 主题 ID：`solbrin`
- 展示名：`Solbrin`
- 交付包：`Solbrin.zip`，压缩包根目录必须直接包含 `theme.json`
- 分页与列表链接使用 `$page.url` 和接口返回的真实 URL，不硬编码分类、标签或文章永久链接
- 评论沿用 Lill 的 `.lill-comment-form` 契约，分页与回复由 Solbrin 的 `theme.js` 接管
- 只新增主题文件；不修改 Lill 后端、默认主题、TriM3 主题或现有站点数据
- 不引入 React、Vue、Astro 或大型动画库；模板、CSS 和原生 JavaScript 完成
- 不下载或依赖参考站的远程视频作为发布必需资源
- 不新增文章类型、数据库表或主题私有内容接口

## 视觉方向

Solbrin 是一套安静的编辑式博客主题，重点是影像与文字之间的连续关系，而不是堆叠组件。

### 色彩

- 场景墨色：`#18202a`
- 场景雾色：`#edf1f3`
- 日间纸面：`#eef2f3`
- 夜间纸面：`#1b1d23`
- 青绿强调：`#287c78`
- 暖铜辅助：`#8c673d`

首页与文章卡片的底色从当前影像下沿取样，保留素材色相；亮素材使用深字和浅色场景底，暗素材使用浅字和深色场景底。场景之外恢复站点主题底色，避免页脚和后续模块被素材颜色污染。

### 字体

- 标题：`"Songti SC", "Source Han Serif SC", "Noto Serif CJK SC", STSong, serif`
- 正文与界面：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`
- 标题不使用负字距；正文保持中文可读行高，长标题允许平衡换行。

### 构图

```text
┌──────────────────────────────────────────────┐
│ rail                                         │
│                                              │
│      影像覆盖首屏，底部融入同色阅读地面       │
│                                              │
│  标题                                        │
│  简介紧接标题下方               长胶囊堆叠   │
│                                         控制 │
│  文章卡片第一排从首屏下缘直接露出             │
└──────────────────────────────────────────────┘
```

内容轴统一左对齐；标题与简介是一个不可拆分的纵向文案组。文章卡片不使用额外的“最近写下”“文章归档”“选读”等说明标题，也不使用装饰箭头。

## 架构

### 模板层

主题目录包含：

```text
solbrin/
├── theme.json
├── index.html
├── post.html
├── page.html
├── archive.html
├── category.html
├── tag.html
├── search.html
├── 404.html
├── header.html
├── footer.html
├── sidebar.html
├── comments.html
├── pagination.html
├── post-card.html
├── theme.js
├── style.css
├── backend/index.mjs
└── assets/
    ├── home-mist.jpg
    ├── home-landscape.jpg
    ├── home-aurora.jpg
    └── avatar.png
```

`backend/index.mjs` 只过滤后台配置的导航候选，不承担内容查询。

### 数据流

1. Lill 的 `bootstrap` 提供 `site`、`theme`、`posts`、`sidebar`、`nav` 和当前页面数据。
2. 首页模板用 `$site.name` 与 `$site.description` 渲染默认文案。
3. 文章胶囊与卡片由 `$posts` 真实数据生成，不写死示例内容。
4. `theme.js` 读取 DOM 数据并完成媒体切换、胶囊展开/选择、侧栏、主题切换和亮度适配。
5. 选择文章后只更新首页场景，不改变文章链接；文章卡片本身仍导航到真实 `$post.url`。
6. 页面刷新或回到默认影像时恢复站点标题与简介。

### 主题设置

- `navigation`：导航项目与顺序
- `hero_media_type`：`image` 或 `video`
- `hero_image`：桌面默认图片 URL，留空使用内置雾景
- `hero_video`：视频 URL，留空不播放视频
- `hero_poster`：视频封面，留空使用默认图片
- `hero_mobile_image` / `hero_mobile_video`：可选移动端素材
- `hero_position` / `hero_mobile_position`：媒体焦点位置
- `hero_tone`：`auto`、`dark` 或 `light` 的取色回退
- `show_sidebar`：是否显示浮动侧栏入口
- `show_prevnext`：是否显示文章前后篇
- `footer_text`：页脚补充文字
- `show_author`、`show_category`、`show_views`、`show_tags`、`show_comment`：文章信息开关
- `custom_css`：管理员自定义样式

所有 URL 留空时都必须有可用回退，不允许出现空白首屏或坏图。

### 核心组件

**场景**：首页影像、保护层、文案、文章胶囊和第一期文章卡片共用一个 `.sr-scene`。场景结束后，后续内容恢复 Lill 应用主题。

**文章胶囊**：最多三条，每条是宽 320px、高 40px 的长胶囊；收拢时叠成 56px 高。悬停只展开，点击才选择。触屏首次点按展开，再次点按选择；方向键移动焦点，Enter/Space 选择，Escape 收起。

**文章卡片**：首期卡片高约 160px，桌面三列、内容区较窄时两列、手机单列。真实封面占右侧约 68%，向左渐融进文字；没有封面时使用调色后的默认影像。

**侧栏**：默认隐藏，桌面以右侧浮层出现，为文案和胶囊留出安全区；手机使用全屏抽屉。侧栏包含导航、最近文章、分类和标签。

**文章详情**：沿用场景色彩作为封面区，正文回到稳定纸面；保留标题、时间、分类、阅读量、标签、前后篇和评论。评论表单沿用 Lill 的核心提交契约。

## 交互与状态

- 默认选中态为空，显示站点标题和简介。
- 选中文章后，标题、简介与影像一起切换；标题使用文章标题，简介使用真实摘要。
- 选择过程中旧影像冻结在当前可见状态，新影像预解码后以 280ms 淡入并轻微缩放；快速切换以最后一次选择为准。
- 胶囊展开 240ms，收拢 240ms；收拢后选中项回到最前。
- 视频静音、循环、`playsinline`；减少动态效果时停在海报。播放被浏览器阻止时保留播放按钮和封面。
- 视频不可用时回退到海报或默认图片，不阻断文案和文章选择。
- 影像离开首屏或页面隐藏时暂停，回到首屏时按用户是否主动暂停恢复。
- 分类过滤只影响当前页卡片；无结果时显示明确空状态并允许重置。
- 主题切换只改变站点纸面、文字、侧栏与页脚，不直接重染影像。

## 响应式与无障碍

- 320×568、390×844、844×390、1024×768、1440×900、1920×1080 均不得横向溢出。
- 标题与简介在桌面保持一组；手机标题和简介可上下排列但间距收紧，文章胶囊放在文案下方。
- 侧栏打开时，桌面内容轴为侧栏预留安全区，不覆盖标题或胶囊。
- 所有按钮有可见焦点、可读标签和至少 36px 的触控命中区。
- 状态更新通过 `aria-live` 播报；选择胶囊使用 `aria-pressed`。
- 减少动态效果时关闭入场、位移、缩放和交叉淡入，保留即时状态切换。

## 错误处理

- 图片加载失败：回退到内置雾景，不重复触发失败循环。
- 视频加载失败：使用海报或默认图片，并保留场景文案。
- 无文章：隐藏胶囊并显示简洁空状态，不渲染空链接。
- 少于三篇文章：按实际数量渲染，胶囊顺序与选择仍有效。
- 分类名称或文章摘要缺失：使用分类默认名和摘要截断结果，不出现 `undefined`。
- JavaScript 不可用：首页仍显示默认文案、文章卡片和可访问的文章链接。

## 验证

1. 用 Lill 模板引擎渲染全部 HTML 模板，确认无语法错误。
2. 通过临时 Lill 服务安装或直接挂载主题，验证 bootstrap 能返回主题页面。
3. 用 Playwright 检查桌面、手机、短屏和侧栏打开状态，截图确认首屏、胶囊与卡片不重叠。
4. 验证真实文章点击、快速连续切换、键盘选择、恢复默认影像、视频暂停/继续和图片/视频失败回退。
5. 验证分类过滤、分页、归档、搜索、404、文章详情与评论表单链接。
6. 验证亮图与暗图的场景底色、文字对比度及场景外主题隔离。
7. 生成根目录含 `theme.json` 的 `Solbrin.zip` 并检查压缩包结构。

## 非目标

- 不迁移 TriM3 的说说、相册、豆瓣、番剧、音乐和复杂小组件系统。
- 不复刻参考站的品牌、站点组件或外部资源。
- 不把首页原型中的测试按钮、静态文章数据或开发脚本发布到主题。
