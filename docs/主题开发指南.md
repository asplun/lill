# lill 主题开发指南

> 适用版本：lill v2.0.0  
> 技术栈：Astro 静态前端 + Node.js 后端（`node:http` + `node:sqlite`）  
> 前后端分离：后端只处理 `/api/*`，主题全部为静态文件，由 Nginx 直接服务。

---

## 1. 主题目录结构

```
frontend/themes/
└── <theme-id>/          # 主题唯一标识，全小写短横线，如 my-theme
    ├── theme.json       # 主题清单（必须）
    ├── index.astro      # 主题入口模板（必须）
    ├── style.css        # 主题样式（可选，推荐）
    └── ...              # 其他静态资源
```

- 主题放在 `frontend/themes/` 下，后端启动时自动扫描注册。
- `theme-id` 必须与目录名一致，且与 `theme.json` 中的 `id` 字段一致。

---

## 2. theme.json 规范

```jsonc
{
  "id": "my-theme",            // 必须，与目录名一致
  "name": "我的主题",           // 必须，后台显示名称
  "version": "1.0.0",          // 必须，语义化版本
  "description": "主题描述",    // 可选
  "author": "作者名",           // 可选
  "settings": [                // 可选，主题设置项（后台「外观 → 主题设置」中展示）
    {
      "group": "外观",          // 分组名，相同 group 的项在后台归为一组
      "key": "color",          // 设置键，运行时通过 val('color') 读取
      "label": "主题色",        // 后台显示标签
      "type": "color",         // 控件类型：color | select | text | checkbox | textarea
      "default": "#4f46e5",    // 默认值
      "options": [             // 仅 type=select 时有效
        { "value": "a", "label": "选项 A" },
        { "value": "b", "label": "选项 B" }
      ]
    }
  ]
}
```

### 控件类型说明

| type | 后台控件 | 默认值示例 | 读取方式 |
|------|---------|-----------|---------|
| `color` | 颜色选择器 | `"#4f46e5"` | `val('key')` |
| `select` | 下拉选择 | `"sidebar-right"` | `val('key')` |
| `text` | 单行文本 | `"10"` | `val('key')` |
| `checkbox` | 开关 | `"true"` / `"false"` | `on('key')` |
| `textarea` | 多行文本 | `"Powered by lill"` | `val('key')` |

> **checkbox 注意**：默认值与读取值均为字符串 `"true"` / `"false"`，用 `on('key')` 判断。

## 3. 主题运行时 API（window.lillTheme）

主题运行时由 `frontend/public/theme.js` 提供，挂载在 `window.lillTheme`。  
配置来源：`/api/v1/options/public` 返回的 `theme_config` 字段（后台「主题设置」保存的值）。

### 3.1 工具方法

| 方法 | 说明 |
|------|------|
| `esc(s)` | HTML 转义，防止 XSS |
| `fmtDate(d)` | 日期格式化（`zh-CN`） |
| `val(key, fallback)` | 读取主题设置，未设置时返回 fallback |
| `on(key, fallback)` | 读取 checkbox 设置，返回布尔值 |

### 3.2 文章卡片

```js
const html = lillTheme.postCard(post);
```

`post` 对象字段（来自 `/api/v1/posts`）：

| 字段 | 说明 |
|------|------|
| `id` / `slug` / `title` | 文章标识 |
| `excerpt` / `html_content` | 摘要 / 全文 HTML |
| `cover_image` | 封面图 URL |
| `published_at` | 发布时间 |
| `author_nickname` | 作者昵称 |
| `category_name` / `category_slug` | 分类名 / 别名 |
| `view_count` | 阅读量 |
| `sticky` | 是否置顶 |
| `route` / `url` | 文章链接（优先使用） |

### 3.3 导航渲染

```js
await lillTheme.renderNav();
```

自动拉取分类与独立页面，渲染到 `#site-nav` 容器。  
当前页自动加 `.active` 类。

### 3.4 侧边栏 Widget

```js
await lillTheme.renderSidebar();
```

根据主题设置中的 `sidebar_*` 开关，自动渲染以下 Widget 到 `#sidebar` 容器：

| Widget key | 说明 |
|-----------|------|
| `sidebar_search` | 搜索框 |
| `sidebar_recent_posts` | 最新文章（5 篇） |
| `sidebar_recent_comments` | 最新评论（5 条） |
| `sidebar_categories` | 分类目录 |
| `sidebar_tags` | 标签云 |
| `sidebar_archives` | 文章归档 |
| `sidebar_meta` | 站点信息 |

### 3.5 应用主题设置

```js
lillTheme.applyConfig();
```

自动应用以下 CSS 变量与 body class：

| 设置 key | 效果 |
|---------|------|
| `color` | `--primary` CSS 变量 |
| `layout` | body class：`layout-sidebar-right` / `layout-sidebar-left` / `layout-full` |
| `content_width` | body class：`width-narrow` / `width-normal` / `width-wide` |
| `custom_css` | 注入 `<style>` 到 head |
| `footer_text` | 写入 `#footer-text` 元素 |

## 4. 主题模板示例

```astro
---
// frontend/themes/my-theme/index.astro
---
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>首页</title>
  <link rel="stylesheet" href="/theme.js">
  <link rel="stylesheet" href="/my-theme/style.css">
</head>
<body>
  <header>
    <nav id="site-nav"></nav>
  </header>
  <main>
    <div id="posts"></div>
  </main>
  <aside id="sidebar"></aside>
  <footer>
    <span id="footer-text"></span>
  </footer>
  <script src="/theme.js"></script>
  <script>
    // 渲染文章列表
    lillAPI.get('/posts').then(d => {
      document.getElementById('posts').innerHTML = (d.items || [])
        .map(p => lillTheme.postCard(p)).join('');
    });
    // 渲染导航与侧边栏
    lillTheme.renderNav();
    lillTheme.renderSidebar();
  </script>
</body>
</html>
```

## 5. 主题设置保存流程

1. 后台「外观 → 主题设置」修改设置项。
2. 前端调用 `PUT /api/v1/admin/themes/:themeId/settings`，body 为 `{ "key": "value", ... }`。
3. 后端存入 `themes.config`（JSON 字符串）。
4. 前台 `theme.js` 的 `init()` 调用 `GET /api/v1/options/public`，读取 `theme_config` 并合并到 `cfg`。
5. `applyConfig()` 应用颜色、布局、宽度、自定义 CSS、页脚文字。

> **缓存**：`theme.js` 会将配置缓存到 `localStorage.lill_theme_cache`，但每次 `init()` 都会重新拉取最新配置，保证后台修改后前台立即生效。

## 6. 默认主题参考

默认主题位于 `frontend/themes/default/`，包含 22 项设置、5 个分组（外观、首页、文章页、侧边栏、页脚），可作为新主题的完整参考。

---

## 7. 新建主题快速步骤

1. 在 `frontend/themes/` 下新建目录 `my-theme/`。
2. 创建 `theme.json`，填写 `id/name/version` 与 `settings`。
3. 创建 `index.astro`，引入 `/theme.js`，使用 `lillTheme.postCard()` 渲染文章。
4. 创建 `style.css`，使用 `var(--primary)` 等 CSS 变量保持主题色一致。
5. 重启后端（`pm2 restart lill-backend`），主题自动注册。
6. 后台「外观 → 主题列表」激活主题，进入「主题设置」修改配置。
